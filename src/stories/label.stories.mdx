# Label Component

The Label component is the root of all typography in a RedSky application. It maintains a consistent set of typography styles
using different variants such as: h1, h2, ... body1, button, etc. Label also maintains many additional props that get passed
as css styles to the appropriate element. Label will use the selected h1, h2, h3, tags when necessary.
