# Avatar Component

The Avatar component requires one prop: `widthHeight`, which takes a `number`. This value will turn into the height and
width of the component. Also, this component can either display an image or the initials of a person's name. If you
provide this component both an image and a name, it will display the image.

## Avatar With Initials

In this example the `Avatar` component has the props, {name: 'Alex Suess', backgroundColor: '#333333', color: '#fff'}.
The outcome is what is displayed below. The component takes in the full name: 'Alex Suess' and returns just the Initials.
