# Checkbox Component

The `Checkbox` component requires the user to create a themes/checkbox.scss file and style the checkbox there.
You can follow the scss layout for the checkbox to get the correct checkbox styles.
The checkbox component uses the Label component as the label text. If label is not desired, then leave the labelText field blank.
