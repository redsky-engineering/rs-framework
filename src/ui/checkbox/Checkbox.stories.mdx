# Checkbox Component

The `Checkbox` component requires the user to create a themes/checkbox.scss file and style the checkbox there.
You can follow the scss layout for the checkbox to get the correct checkbox styles.
The checkbox component uses the native label tag to use Reacts htmlFor.
This requires the id for the input to be set so the label can use that id to connect it using the htmlFor react prop.
This is done by setting the input id with the props `checkboxId`. This id needs to be unique to each checkbox and label so that the label and checkbox click events will link up properly.
If for some reason a label is not desired, then leave the labelText prop field blank.
The checkbox also utilizes RsFormControl. To see an example of this being utilized, Look at the ComponentDemoPage for more information.
