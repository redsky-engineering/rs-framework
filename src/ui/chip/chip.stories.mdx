# Chip Component

The Chip component requires one prop: `widthHeight`, which takes a `number`. This value will turn into the height and
width of the component. Also, this component can either display an image or the initials of a person's name. If you
provide this component both an image and a name, it will display the image.

## STANDARD LOOK

**_Standard_** is one of the two properties that can be passed to the `look` prop. By default, the background color is
`#616161` and color is `#ffffff`. These values can be changed by using the `backgroundColor` and `color` props.

### Chip

## OUTLINED LOOK

Outlined is one of the two properties that can be passed to the `look` prop. By default, they will have a transparent
background with a `1px solid rgba(255,255,255 0.23)` border. The border **CANNOT** be changed with any of the existing
props.
